# **App Name**: Kuro Vault

## Core Features:

- Dynamic Product Grid: High-contrast card display featuring isolated product images, stock status indicators, and integrated S/. pricing labels.
- Rapid Filtering System: Seamless, single-page navigation bar to filter inventory by categories like Shoes, Hoodies, and Accessories without page reloads.
- Kuro Style Matcher: A generative AI styling tool that analyzes your aesthetic preferences to recommend the best matching items from the current drops.
- Direct Messenger Integration: Dynamic m.me link generation on each product card to launch a pre-filled purchase inquiry directly to the brand team.
- Streetwear Motion System: Suttle, premium hover effects and micro-interactions for the 'Recent Drops' section to reinforce the urban brand identity.
- JSON-Driven Catalog Manager: Independent data structure implementation that allows for easy inventory updates and price adjustments across the entire SPA.

## Style Guidelines:

- Primary Color: Vibrant Mustard (#FDB813) for interactive elements and brand high-lighting, chosen for its high-energy urban feel.
- Background: Near-pure Black (#0D0D0D) providing a premium, industrial-streetwear foundation.
- Accent Color: Deep Amber (#B37700) used for subtle dividers and muted secondary states to create depth.
- Headlines: 'Space Grotesk' for a computerized, industrial tech vibe. Body: 'Inter' for high legibility and a modern, neutral look.
- Asymmetric hero section featuring high-impact bold typography paired with a repeating multi-column grid for product cards.
- Industrial-style transitions using clean ease-in-out timing for stock badges and product highlights on hover.
- Minimalist geometric icons with thin strokes to maintain a clean, high-fashion aesthetic across product CTAs.
